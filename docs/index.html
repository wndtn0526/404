Filter Bar · 데이터 테이블 필터

<x-filter-bar> — 검색 + 필터 pill + 「총 N건」을 한 줄로 묶어 표 바로 위에 둔다. 검색창을 표와 분리해 따로 두지 않는다. 청담원 플랫폼 저장소에서 옮겨 왔다.

필터 항목

총 128건

⚠️ 팝오버·드롭다운 패널 반경은 원본의 12px 단계를 우리 스케일 최대값 6px 로 내렸다. 모서리가 2px 덜 둥글다.

워크스페이스 셸

<x-workspace-shell> — 워크스페이스 레일(54px)이 붙은 다크 LNB + 배경 투명 GNB. 출처는 디자인 가이드가 아니라 워크스페이스 화면 파일(node 1-299)이다.

아래 GNB·LNB 와 역할이 겹친다. 화면 단위로 하나만 고른다 — 섞으면 헤더가 두 겹이 된다.

전체 화면을 차지해서 여기에 끼워 넣으면 레이아웃이 깨진다. 실물은 /contents 에서 본다.
